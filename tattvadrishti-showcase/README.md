# TattvaDrishti Showcase

A standalone, presentation-focused website for TattvaDrishti. This folder does not depend on the operational FastAPI application and can be deployed directly to Vercel.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy to Vercel

Import the repository in Vercel and set **Root Directory** to `tattvadrishti-showcase`. No environment variables are required.

The interactive narrative analysis is intentionally a labelled frontend simulation for demonstration and education. It does not call the project detection backend and must not be treated as a factual assessment.
